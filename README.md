# Interactive Algorithm & OS Visualizer

## 📖 Overview
An interactive, web-based visualization platform designed to bring complex algorithms and Operating System concepts to life. This project features real-time animations and a dedicated benchmarking environment to help users understand the underlying mechanics and efficiency of various computational processes.

## ✨ Key Features
* **Real-Time Animations:** Step-by-step visual execution of algorithms to enhance conceptual understanding.
* **Comparison Arena:** A dedicated module for side-by-side algorithm benchmarking.
* **Live Metrics:** Dynamic tracking of time complexity, step-counts, and execution times as algorithms run.
* **Interactive UI:** Users can customize inputs, adjust execution speeds, and pause/resume animations.

## 🧩 Core Modules (6 Interactive Modules)
1. **A* Pathfinding:** Visualizes the shortest path calculation on a grid with obstacles.
2. **CPU Scheduler:** Simulates OS process scheduling algorithms including:
   * First-Come, First-Served (FCFS)
   * Shortest Job First (SJF)
   * Round Robin (RR)
   * Priority Scheduling
3. **Memory Allocator:** Demonstrates how memory blocks are allocated to processes (e.g., First Fit, Best Fit, Worst Fit).
4. **Sorting Visualizer:** Animates the sorting process for various array-sorting algorithms.
5. **Comparison Arena:** Benchmarks multiple algorithms against each other simultaneously.
